## 2. Roles
- **Admin** (custom claim `admin`): everything; NOT a competitor (excluded from points, tables, picks, auto-fill, H2H). Created from `ADMIN_EMAILS` at first login.
- **Games manager** (claim `gameManager`, set in Admin -> Users -> Details): a normal PLAYER who also gets only the Games tab: add / import (future games only), edit / cancel / delete games that have NOT started; never scores or results (enforced in `firestore.rules` + server). Needs sign-out/in to take effect.
- **Player**: registers himself with first + last name (any language, 2+ letters each, unique name, no list needed; the admin's "pre-add names" box is optional and such a name is claimed by exact match). **Can submit predictions / bonus answers only after the admin ticks "שולם" (paid)**; unpaid = can browse, is hidden from tables, not scored, not auto-filled. Phone + email mandatory. Name read-only for the player (admin renames).
- Blocked players: cannot sign in / save; auto-fill skips them.

## 4. Scoring and game rules (owner-approved unless marked)
- Competition = regular season only (`round 'RS'`, NBA Cup games count), final score INCLUDING overtime. Planned ~1-2 games a day (~255 games), chosen by the games manager; season Oct 20 2026 - Apr 11 2027 (~25 weeks).
- Points (**changed 2026-10-18**): correct winner 5; **exact margin +6** (`diffExact`, right winner and the exact difference between the teams); an **exact score of both teams = 5 + 6 + 6 = 17** (`exact` = +6 ON TOP of the winner and the exact margin: an exact score has the exact margin too); margin tiers for an error of 1 or more (error 1:+4, 2:+3, 3:+2, 4:+1; `diffBonus`, owner did not change them); unique exact score +5 (22 total); **unique exact MARGIN +5** (`uniqueDiff`: the only manual player with the exact margin and NO exact score = 5 + 6 + 5 = 16; one unique bonus per game; a player with the exact score blocks it for others; auto-filled never gets it and doesn't block); risk +2; **the joker doubles EVERYTHING of that game**. Max per game 24 (48 with joker). The live values are in `appSettings/main.scoring`: if it was saved before, Admin -> Scoring must be opened, `exact` set to 6 and `diffExact` to 6, Save, then Recalculate all points. Other points: risk bonus when <=10% picked the right winner (**points = 2 is only a PLACEHOLDER: owner must confirm**), joker x2 (jokers per season: default 3, **owner is choosing; simulation suggests ~8**, editable until the season starts), auto-fill: random 20-99 per team, margin 1-30, 50% points floored, never unique. Tiebreakers: total > exact > unique > bonus. Admin edits every value in Admin -> Scoring (one editor). Jokers on deleted / cancelled games are free again.
- Bonus types: numeric, closest, choice, team, player (per-question player LIST), dynamic_score, text, ranking (East+West: owner set pool **60, 1 point lost per place**; simulation warned this is strict, 0.5-0.7 would let most players score), division_team, conference_team. Display order by type (admin can override with arrows). Bonus value balance: simulation says bonus ~9% of points at the assumed values; owner may double them.
- Head to Head: group league -> knockout -> pairs for fun; game points only; tie order exact hits, unique hits, better seed, admin decides (World Cup tie rule never provided).
- Star of the night (Home): top GAME points in the latest complete game night (08:00-08:00 Israel); logic is the assistant's own, **owner has not confirmed it matches the World Cup**.
